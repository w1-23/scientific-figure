# 通用线条、曲线、填色与自审规范（目标0.9）

实际能力基线Engine0.8.0；0.9新增入口的状态和契约见[语义规划工作流](../docs/semantic-planning-workflow.md)，不因本规范描述了流程就宣称API已实现。当前宿主就是负责理解和看图的模型，无第二模型。参考任务先读[复刻指南](reference-reconstruction.md)，自然语言任务先读[设计指南](text-design.md)，画法取舍见[构造选择表](construction-selection.md)。

复杂图先确定信息结构、必要部件、关系、文字/色义与具体未知，再落几何。自然语言任务分别记录用户明确内容、设计选择与科学假设；不擅加制备/给药或具体机制。简单扁平图可从简短意图直接构造并预览，不强制检索或多份规划文件。FigurePlan是输入草稿，未选构造可保持unresolved，不建立第二对象图。

方法由结构与画风决定：Recipe缺少必要部件时必须回退自由程序或混合构造。宿主可显式运行Python/JavaScript，用自己的函数、局部坐标及成熟库生成Scene。新候选经校验与[工程事务](../docs/generation-and-effects.md)接受：B=上次纯生成，U=当前用户Scene，C=新纯候选；先读diff合并预览及冲突，再按revision接受，同字段异改保U并报告。Scene是唯一当前状态，Plan/源码/参数不暗改用户现图；打开工程/Bundle、diff、accept均不执行保存源码，python -I不是安全沙箱。

实际预览按模块/连接→轮廓/比例/孔洞→必要内部结构→颜色/层次→文字检查。白色盖块不能冒充真孔洞；静态布尔不等于持续穿插。Plan0.3 semantic不默认分色、搜索或骨架；[像素流程](../docs/adaptive-reconstruction.md)与第4节只用于明确的像素任务，旧格式兼容。细胞、柑橘等是输入实例，不是引擎固定科学词表。

## 1. 先确定线条在表达什么

| 视觉要素 | 首选表达 | 不应采用的默认做法 |
|---|---|---|
| 物体外边界 | 闭合 path，平滑部位用三次贝塞尔，真实尖角保留折点 | 逐像素放置大量节点；把所有角都磨圆 |
| 引线、流程边、中心线 | 开放 path + stroke + 独立箭头属性 | 将线条厚度描成一个狭长的填充多边形 |
| 膜、褶皱、叶脉等内部线 | 命名的独立开放路径或有科学意义的薄带 | 当成噪点删掉；仅靠外轮廓替代内部结构 |
| 带孔洞的填充区域 | 一个 compound path，多 subpath，保留 fill-rule | 分成独立填充块，把孔洞填实 |
| 多结构生物素材 | 语义组 + 可独立修改的边界、内部结构、文字 | 给整张描摹碎片套一个组名后宣称语义重建完成 |

描边宽度用场景单位定义，按最终展示尺寸检查可读性。优先统一同一角色的线宽、圆角端点和连接形式；不要将所有线宽统一到失去层级。标注线应轻于物体主轮廓，机制箭头与抑制符号必须由研究语义决定。

## 2. 曲线如何重绘

- 用尽可能少的控制点表达主形态；控制柄沿切向，避免无意义的细碎波动。
- 区分真实锐角和栅格台阶。当前拟合器用弧长邻域估计转向，在角点拆分，在平滑段做弦长参数化与最小二乘三次贝塞尔拟合；误差过大时递归拆段。
- 每个闭合环独立保留，避免把内外边界连接起来。不能仅检查拟合点误差：点之间可能过冲、交叉或封闭小孔，必须重新渲染。
- 当前 `fit_stroke` 仍仅支持单连通细直线。0.3 的 `stroke_layers` 另提供有限暗细带曲线/分支候选，`region_bands` 用像素单元边界保留细带；见 [内部结构契约](../docs/internal-structure.md)。亮线、密集纹理、复杂交叉、箭头角色仍需宿主证据，不合条件明确拒绝。
- 不承诺恢复原设计控制点。目标是可编辑、结构正确且在容差内更简洁的曲线。

## 3. 填色如何决定

先给颜色命名其用途：材料/结构域、分组类别、状态/信号、照明/体积。不要因为颜色接近就自动合并承担不同科学含义的区域。

- 扁平图默认由宿主给明确的对象填色，不量化整图。仅在显式旧 trace 辅助中，palette 首色是移除的背景、其余按最近 RGB 分配；HSV 也只是局部证据工具，不定义科学对象。
- 调色板应覆盖主体颜色、背景和必须保留的白色内部区域。白色可能是孔洞，也可能是实际物体；必须结合遮罩与语义判断。
- 渐变：只在原图或设计确实表达连续明暗时使用。Scene0.3支持显式linear_gradient和radial_gradient，不自动从图片推断光照或参数；扁平参考不强加体积光影。
- 层叠：绘制顺序是组内子对象顺序；半透明组先整体合成，再施加 opacity。不得对每个子路径单独乘组透明度。
- 填色应检查裂缝、重叠、孔洞、遮挡、边缘光晕和色带。碎片过多先回到对象分离和调色板选择，不默认用更多颜色追逐像素相似度。
- 色彩预算超标时报告给宿主；自动减少颜色可能抹去重要类别，因此引擎不会静默重着色。

## 4. 机械自审与自动修正

`trace_region` 在每个输入区域上执行：

1. 获取未简化的像素中心轮廓作为几何基线。此基线不是原始矢量，也不是科学真值；小区域过滤本身也有损失。
2. 按计划参数简化轮廓，拟合保留锐角的贝塞尔曲线。
3. 用交付 PNG 相同的 resvg 渲染器，逐路径比较掩膜，检查 IoU、95% 边界偏差、连通域/孔洞数量、预乘 RGBA 填色差异、段数和颜色预算。
4. 不通过则降低简化和曲线容差，最多三轮。最后可退回未平滑轮廓；复杂度仍超标或颜色预算不满足时保留 needs_review。
5. 每轮写明参数、指标、拒绝原因与最终策略。不因某项几何指标通过就宣称科学或审美通过。

默认策略：`smooth=true`、`curve_tolerance=0.8` 场景单位、`min_iou=0.96`、`max_boundary_error_px=1.2`、`max_rgb_mae=0.025`、`max_segments=1600`、`max_rounds=3`、`color_budget=12`。这些是原型工程默认值，不是普适科研出版标准；需按输出尺寸及形态重要性调整。

可在 Plan 顶层 `drawing_policy` 设默认值，在单个 trace step 的 `policy` 覆盖。细胞膜小孔等关键细节应更严格；不能为了通过而不断放宽阈值。

## 5. 宿主视觉与科学自审

宿主每轮读取实际当前SVG生成的PNG：先按目标尺寸看全图，再看关键局部；参考任务看同尺度源区域，替换旧图时看参考/旧/新对照。按object_id记录issue、evidence、action、remaining_uncertainty；整体问题用$scene。动作须可执行，如换构造、调开口、补必要褶线、修连接端点或补取证，不能只写“提高质量”。

推荐修正顺序：模块/连接 → 大轮廓/比例/孔洞 → 必要内部结构 → 填色和层次 → 文字。若模板先天不覆盖结构，先换方法再调参数；未知无法消除则保留，不用装饰掩盖。

引擎 `qa.json` 检查越界、过细描边、可能被描成填充块的细线、全局颜色预算以及各像素操作的自审结果。修改工程后，旧像素自审会标为 stale_after_edit；应重新看图。每轮修正只改目标 ID 及其明确依赖，记录基准 revision。

默认最多三轮定向修正，每轮只改目标ID及明确依赖，渲染后再看。停止时报告已通过、未执行、未解决项及实际支持程度；视觉记录绑定当前Scene/preview，修改几何、资源或渲染后旧结论过期。机械检查、宿主视觉与科学审核分开，测试通过、对象名称或路径数不证明视觉质量或科学正确；科学审核未做就标未执行，不自动设为交付门槛。科学关键关系无依据时保留未知或请求必要澄清，不能为美观补造。

## 6. 证据、风格与组合

新版 `evidence` 是有独立预算的观测接口，不能把小图放大板当作新增信息。默认contrast；detail/palette按需。实际panel和source/ROI/board映射必须随证据保留。它不更改本规范旧像素自审的512×512约束。

context/profile/text/layout是来源与意图，当前几何/文字/样式以Scene为唯一权威。初建仅执行宿主显式token binding；更换profile不暗改现图。机械style-check与宿主风格判断分开。Scene0.3支持径向渐变和数值虚线；字体缺字及不支持的rich text、字重/fallback不能静默接收。文字保持真text，参考转录保留original/normalized/suggestion/uncertainty；自然语言任务区分用户标签与拟写文案。建议未经明确采用不改入当前文字，测量/wrap只提供指标或建议，不自动排版。

多素材逐成员保存并用bundle封装完整工程。组合前由宿主声明实例变换、背景策略、容器、文本与连接端点；移动实例使用其wrapper ID，编辑部件使用记录的ID map。整体组合需要新复核，成员通过不能替代整体通过。完整工程中的connector保持live；选中对象静态导出会将其冻结为path。

低清交织结构、复杂膜带等关键结构未通过时，保留失败及不确定性；测试/路径数/视觉相似不能掩盖错误。最多三轮修正达限后仍失败就如实交付开发结果，不标最终视觉验收通过。

## 7. 复用、能力与保护边界

分别披露实际采用的外部素材（作者/许可、版本/摘要、改动）、绘图代码（包括自家函数的文件/版本、复用部件和修改）及几何/渲染库（实际库/版本与用途）。方法借鉴与外部代码移植分开；复制代码另保留固定SHA、文件、许可和通知。素材在Registry中存在不等于本图采用。明确冻结栅格的对照不偷换官方SVG；合法生产复用可用但须单列来源。

旧像素机械自审区域最多512×512；独立evidence有自己的预算。暗细带中心线仅有限支持。现有受控SVG导入只接受文档子集，不是任意round-trip；无自动公式/OCR、复杂滤镜/纹理重建或科学真伪认证。Recipe目录有限，不虚构mouse/flask/avatar模板。测量与候选不自动获得语义角色，不自动写入Scene。当前核心CPU，不新增模型服务/训练、GUI、第二几何后端或大素材库。

私有参考、题图程序及派生工程仅本地分包，不进公共源码/示例；不复制系统字体、环境或权重。SVG不含嵌入位图、脚本和外链，PNG从同一SVG渲染。本项目独立于QAagent，不初始化Git、不提交推送、不启动部署服务，不修改网络/安全设置绕过限制。正式pilot、48项来源隔离评测、独立宿主消融、人类盲评、领域审核、Runtime首轮接线、跨版本模板迁移及实验轮廓扩展均不恢复为当前任务或交付门槛。
