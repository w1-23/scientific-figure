# v0.8 历史整图重绘示例

此目录为用户指定发布的完整参考图与本项目 v0.8 整张重绘，不是 v0.9 新视觉成绩。

- `reference.png`：用户提供的完整参考图保存 PNG 视图，1055×1113；原作者/论文来源未核实。
- `full-redraw.svg`：v0.8 整张可编辑矢量重绘，包含上方制备／给药流程、右侧肿瘤与血管、左下细胞放大图、图例和底部色板；672 对象、22 真 text。
- `full-redraw.png`：由同一整图 SVG 渲染的 PNG 预览。

本目录不发布细胞局部裁图。整图的主要部件可独立编辑；ER 形态、小鼠解剖、载体剖面及笔绘边缘仍有近似，未做领域科学审核。原图疑似错字在主结果中保留。对象名称不认证科学识别正确性。
