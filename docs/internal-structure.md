# 0.3 内部结构恢复：契约与开发验证

日期：2026-11-17。引擎 0.3.0，Plan 0.2 / Scene 0.1 保持兼容。本机 Anaconda `ScientificFigure_skill` / Windows / Python 3.12 / CPU / resvg-py。没有新增运行依赖、图像模型、服务或题材专用分支。

## 问题与本轮变化

0.2 生物局部的整体占据几乎是矩形，单色面域能得到 silhouette IoU=1.0，却漏掉几乎所有内部可见内容。原来的 OpenCV 像素中心轮廓还会缩窄细带，完全丢弃面积为零的一像素曲线。单纯收紧平滑误差或增加颜色数量不能修复这个表示问题。

本轮增加三项相连的能力：

- 源图独立的内部 RGB 对比边界证据及覆盖检查，不使用候选的颜色分割充当源真值。
- `region_bands`：感知颜色分区与像素单元边界，连续底色加内部面域；小闭环保持精确，大轮廓有限拟合。
- `stroke_layers`：对暗细带提出底色与开放中心线/分支的不同绘制假设；输出真实 stroke，可单独改线宽、颜色和位置。

`repair action=auto` 能由实测的 `internal_boundary_missing` 进入 `restore_internal_boundaries`，而非继续对整体轮廓反复平滑。

## 源证据与机械检查

`analysis.json` 新增可选 `internal_structure`，旧分析仍可读取。记录 `method=rgb-contrast-v1`、内部边界像素数、暗细带像素数及有限像素图的端点/分支诊断。证据只称为 observed RGB contrast，`scientific_identity=unknown`。图过密时写 `unresolved_budget`，不伪造关系图，也不让分析因此整体失败。

边界计算使用合成后的各 RGB 通道、轻微 Gaussian 处理及 Canny，并排除源占据外边界/真孔洞的邻域。评价在源区域坐标上重算双方边界，报告：

- `F.internal_boundary.coverage`：源对比边界在候选 1.5 像素内有匹配的比例。
- `precision`：候选边界得到源边界支持的比例，作为额外边缘诊断。
- `components`：至少 12 像素的源可见边界连通分量覆盖和 bbox。
- 总证据至少 12 像素才启用硬约束；工程默认 `min_internal_coverage=0.72`，同时任何被测源分量覆盖低于 0.5 都报告遗漏。

这些阈值是通用工程起点，尚无跨域标定，不是出版标准或科学置信度。覆盖高不能证明连接、端点、交叉、自交、箭头方向或遮挡正确。点噪声、纹理和注释也可能形成边界。颜色、可见拓扑、实际编辑任务和复杂度仍分别检查；内部边界通过不能覆盖它们的失败。

## 新的候选表示

### region_bands

确定性的双边处理降低小幅颜色噪声；在源可见 RGB 的量化直方图上做带频数的 Lab 聚类，固定初始化/迭代上界。使用与宿主给定相同的颜色预算，不靠增加全局颜色/路径预算获得通过。宿主明确提供的颜色可作为额外候选色，最多 16 色。

每个像素视为 `[x,x+1] × [y,y+1]` 单元。取消相邻像素的共享边，追踪闭环，保留一像素细带、点接触、孔洞及岛。单个复合路径可包含同一绘制色的多个可见区域，不能因此声称它们是同一个科学对象。

小闭环只合并共线边，保持精确；长闭环按 0.45 像素采样残差有限拟合。拟合不保证全局 Hausdorff 或无自交，最终必须源图重渲染检查。段数仍计入原复杂度预算，不能通过把碎片装入一个 path 隐藏边界成本。

### stroke_layers

在亮度图上用局部闭运算响应提出暗细带，有限 Zhang–Suen 细化后构建像素邻接图，在端点和分支处拆成链。无必要的对角捷径不进入图。骨架的分支是可见图像假设，不代表科学连接。

底层表面由被提取细带的有限 inpaint 假设重建，上层为实际开放路径。路径固定观察端点，拟合 L/C，按距离变换估计线宽；每条可单独改色、改线宽、移动、隐藏和导出。inpaint 只在生成表面候选时使用，输出 SVG 不含这张位图，也不宣称恢复了隐藏科学形状。

当前只处理有局部亮背景支持的暗细带。亮线、宽度剧变、密集纹理、短孤立点、复杂交叉和多色连续笔画仍可能失败；超过 512 条链明确拒绝该候选，不截断后冒充完整。真实生物局部当前触及此限制，所以本轮交付的改善来自 `region_bands`，不能写成已自动恢复该图全部中心线。

## 路由、选择与修复

默认保留基本几何、自由轮廓、旧颜色层；源内部边界证据达到 12 像素时，在默认四候选预算内追加 `region_bands`。`stroke_layers` 可在 Plan `parameters.methods` 显式选择，或进入内部边界定向修复搜索。

通过硬约束的候选仍采用 Pareto / 外观容差 / 复杂度选择。全部不合格时，旧版简单计算“失败原因数量”可能让空白单色块胜过含内部结构的复杂候选。本轮将 best effort 顺序改为：必须编辑任务缺失数、内部边界覆盖、颜色误差、外轮廓误差、段数。它只是供复核的未通过成果；全部拒因和 `needs_review` 保留，不能被描述成合格候选。

修复动作：

```json
{"action":"restore_internal_boundaries","max_rounds":2,"budget":{"max_candidates":4,"max_renders":12,"max_seconds":30}}
```

`auto` 按实测失败选同一动作。只有内部边界覆盖实际提高、局部所有约束通过、revision 子树替换合法且整图复评通过才提交。无改善、候选过密、超预算或上下文不合格保持原 Scene。不能因为新结果看起来略好就把失败工程自动提交成成功修复。
