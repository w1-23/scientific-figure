# Scientific Figure Skill 完整执行计划

修订：2026-11-18，按用户对绘图目标和范围的最新纠正更新。Engine 当前为0.8.0。本文件完整替换上一版计划的执行范围；历史交付事实保留在[0.8交付说明](delivery-0.8.0.md)，不修改旧包或旧成绩。

## 1. 目标与完成条件

让宿主根据参考图或自然语言要求，使用合适的合法素材、已有绘图代码、参数化构造和自由Python/JavaScript程序，画出结构清楚、视觉接近要求、主要部件可独立修改的科研矢量图。SVG是实际矢量结果，PNG由同一SVG渲染，完整工程保存可编辑状态。

**让模型决定怎么画，让引擎负责画好。** 当前执行宿主就是调用本Skill的会话助手。Skill内部没有另一个负责看图或科学推理的模型。引擎负责明确的几何、层级、样式、关系、保存、编辑和导出，不自动补全科学含义。

完成一张图需要：实际读取参考或要求；保留主要对象、必要内部结构、连接和文字；实际读取当前预览并修正；交付SVG、同源PNG和工程；检查主要部件编辑及局部导出；如实说明仍有的近似。替换旧版时，与旧版和参考在相同尺寸下对照，不能仅凭接口或测试通过宣称画得更好。

不针对几张示例图编写引擎专用逻辑；允许题图绘制程序保存在私有输出目录。不为了平滑牺牲真实结构，不为了像素相似堆大量无意义路径，不嵌位图冒充矢量，不让几何自审代替科学含义判断。不破坏既有CLI、Scene、SVG、PNG、对象编辑和导出接口，保持本地Agent与无GUI Code Worker文件调用兼容。

## 2. 当前范围与明确撤出的事项

当前主线是使用现有能力把图画好，并修正妨碍绘图的具体问题。Recipe、FigurePlan、Registry、证据工具都是可选工具；不要求每张图先套Recipe或新增协议。

用户已明确不需要以下工作，现从必做任务、验收门槛和待办路线中撤出：

- A—E独立宿主消融、12项正式pilot和48项来源隔离评测。
- 三名人类盲评、领域科学审核或认证。
- 真实Runtime首轮钩子接线。
- 跨版本模板部件迁移。
- offset与变量宽轮廓实验扩展。

这些撤出不表示它们已经实现或通过；后续不再以这些事项阻塞绘图交付或作为自动建议的后续任务。已有实验函数不删除、不扩展，不以其存在证明通用能力。

不新增模型服务、训练系统、供应商SDK、GUI、PPT/Illustrator主后端、第二几何后端或素材市场。不启动服务或部署。本项目独立于QAagent，不初始化Git、不提交或推送该仓库。当前引擎CPU运行；QAagent的GPU规则不改变这一事实。

## 4. 实际执行链

参考图/自然语言 → 当前宿主理解对象与结构 → 选择合适的素材或绘图方法 → 宿主写程序/直接Scene/可选Plan → 几何库计算 → 引擎校验Scene → SVG → 同源PNG → 宿主读取全图和关键局部 → 按对象修正 → 保存、编辑验证和交付。

Scene是当前几何、文字、样式、层级和可执行关系的唯一权威。FigurePlan、程序、参数和来源是构造输入快照；preview、manifest等是派生物。

新工程可直接构造。重跑已有且可能被用户编辑的工程，使用B/U/C：B是上次纯生成基线，U是当前用户Scene，C是新纯候选。U-only保留、C-only采用、同字段异改保U并报告冲突；成功纯基线更新为C，不是混入用户编辑的结果。path、矩阵和数组原子比较；显式dependency_frames只在合法共同局部框架内忽略共同整体移动，不放宽旧记录。

加载工程、Bundle、render、diff和accept均不执行保存源码。宿主自写程序由正常工具显式运行；python -I不是安全沙箱，不自动执行未知上传脚本。

## 5. 绘图方法选择

### 参考重绘

先看参考，明确构图、轮廓、比例、必要内部结构、遮挡、文字及颜色意义。方法以该对象的实际需要为依据：少量Bezier/原语、中心线加描边、真渐变、复合填充、部件层叠、面域布尔或许可明确的素材均可组合。

合适时复用已有局部构造函数；不合适则自由构造。不能为了Recipe命中率把复杂膜、胞器、小鼠或组织简化成默认ellipse。复用素材须检查结构和画风是否匹配；没有合适资源时不为展示“复用”强行加入无关图标。

### 自然语言原创

按用户给出的目的和明确对象/关系设计版式；宿主作正常绘图判断，不凭常识暗加实验步骤、剂量或因果。文字保持可编辑，连接目标明确。未知科学内容单列，缺少外部审核不阻塞用户未要求审核的绘图。

### 多素材和图组

宿主拆分模块、选择独立编辑单位，提供摆放、连接和背景策略。成员使用完整工程或Bundle，组合保独立实例和来源。全图实际查看，成员预览不能代替组合预览。静态选中导出冻结connector及外部occlusion影响，完整工程保live关系。

## 6. 素材与库复用的准确说明

每次交付分别写清三类复用：

| 类型 | 记录 |
|---|---|
| 外部现成artwork | 实际用到的文件、作者、URL、版本、许可、SHA和修改；没有使用就明确没有 |
| 绘图代码/构造复用 | 复用哪个已有函数/程序及本次改动；不能冒称下载了外部科学素材 |
| 几何和渲染库 | 实际使用的FontTools、skia-pathops、resvg等；不能把库算成现成插画 |

Registry目前唯一外部artwork为Twemoji lemon14.0.2、CC-BY4.0；15 Recipe为原创几何构造，2族为元数据。旧纳米载体图使用宿主绘图程序，没有外部科学artwork。新接口柠檬例也没有使用Registry源SVG。

资源受控导入先转Scene，不能直接拼任意SVG字符串。拒绝script、外链、DTD、实体、位图和不支持属性；不以栅格化绕过。私图和派生物只本地交付；系统字体只记需求与摘要。不使用官方源SVG替换已冻结的栅格重绘任务。

## 8. 检查与停止规则

每轮检查主结构与连接 → 轮廓/比例/孔洞 → 内部结构 → 填色层次 → 文字和细节。查看当前实际输出，定位到对象ID；保留接受的局部，不为修一处重绘整图。默认最多三轮定向修正，仍有近似就如实交付，不伪造通过。

工程验证只覆盖真实风险：Scene合法、引用闭合、保存重开、真文字、SVG/PNG同源、编辑隔离、局部导出、用户修改不被覆盖。核心代码未改且无新失败时，不无故重跑全量测试或重建环境；文档和题图程序不堆镜像测试。

必要孔洞被填死、连接错目标、必要文字丢失、用户编辑被覆盖或位图冒充矢量需要修复。低清未知不补造隐藏拓扑；不把装饰路径增加称为结构恢复。宿主视觉判断与机械检查分开，科学审核只在用户另行要求时安排。

网络/许可/权限受阻保留事实，不改网络或安全设置绕过。历史失败不改成passed。新候选失败不改变当前用户工程；新输出与历史目录分开。
